# DSA practice questions

> Practice list by topic and difficulty (arrays, linked lists, stacks, hashing, recursion, trees, graphs, sorting), then logical and math problems.

## By topic

### 1. Arrays and Strings

#### Easy:

1. Find the largest/smallest element in an array.
2. Reverse an array or string.
3. Remove duplicates from a sorted array.
4. Implement two-pointer technique to check if an array is a palindrome.
5. Check if two strings are anagrams.
6. Move all zeros to the end of an array without changing the order of non-zero elements.
7. Find the missing number in an array of size `n` where elements are from 1 to `n`.

#### Medium:

1. Rotate an array by `k` elements.
2. Find the longest common prefix among an array of strings.
3. Longest Substring Without Repeating Characters.
4. Find the maximum product subarray.
5. Find all pairs in an array that sum to a given value.
6. Find the longest palindromic substring.
7. Sort an array of 0s, 1s, and 2s without extra space or sorting algorithm.

#### Hard:

1. Median of Two Sorted Arrays.
2. Longest Substring with At Most Two Distinct Characters.
3. Minimum Window Substring.
4. Find the first missing positive integer.

### 2. Linked Lists

#### Easy:

1. Reverse a singly linked list.
2. Detect a cycle in a linked list.
3. Merge two sorted linked lists.
4. Find the middle of a linked list.
5. Delete a node from a singly linked list, given only access to that node.
6. Remove duplicates from an unsorted linked list.
7. Find the length of a linked list.

#### Medium:

1. Remove the nth node from the end of a linked list.
2. Add two numbers represented by linked lists.
3. Detect the start of a cycle in a linked list.
4. Merge k sorted linked lists.
5. Reverse a linked list in groups of `k`.
6. Clone a linked list with random pointers.
7. Flatten a multilevel doubly linked list.

#### Hard:

1. Reverse nodes in a linked list between two given positions.
2. Sort a linked list using merge sort.
3. Reverse alternate `k` nodes in a linked list.
4. Rotate a linked list to the right by `k` places.

### 3. Stacks and Queues

#### Easy:

1. Implement a stack using arrays.
2. Implement a queue using stacks.
3. Valid parentheses check.
4. Find the next greater element in a circular array.
5. Evaluate a postfix expression.
6. Implement a min stack that supports push, pop, and retrieving the minimum element in constant time.
7. Implement a basic circular queue.

#### Medium:

1. Implement a deque using stacks.
2. Largest rectangle in a histogram.
3. Implement a priority queue using an array.
4. Simplify a file path using a stack.
5. Design a stack that supports push, pop, top, and retrieving the max element in constant time.
6. Sliding window maximum.
7. Implement a LRU (Least Recently Used) cache.

#### Hard:

1. Design a max stack.
2. Longest valid parentheses.
3. Remove the k-th smallest element from a stack.
4. Trapping Rain Water problem using stacks.

### 4. Hashing

#### Easy:

1. Two sum problem using a hashmap.
2. Group anagrams together.
3. Check if a string is a permutation of a palindrome.
4. Find the first non-repeating character in a string.
5. Find intersection of two arrays.
6. Check if two strings are isomorphic.
7. Count the frequency of elements in an array.

#### Medium:

1. Subarray sum equals `k`.
2. Longest consecutive sequence in an unsorted array.
3. Find the longest substring with `k` unique characters.
4. Minimum window containing all characters of another string.
5. Implement an LRU Cache.
6. Find the number of subarrays with sum equal to 0.
7. Longest substring with at most two distinct characters.

#### Hard:

1. Word break problem.
2. Longest substring with at most `k` distinct characters.
3. Find the smallest subarray covering all elements of another array.
4. Find all anagrams of a string in another string.

### 5. Recursion and Backtracking

#### Easy:

1. Generate all subsets of a set.
2. Print all permutations of a string.
3. Find the nth Fibonacci number.
4. Tower of Hanoi problem.
5. Calculate the power of a number recursively.
6. Solve the factorial of a number using recursion.
7. Sum of digits of a number using recursion.

#### Medium:

1. N-Queens problem.
2. Word search in a 2D grid.
3. Combinations of numbers that sum to a target.
4. Letter combinations of a phone number.
5. Generate parentheses.
6. Palindrome partitioning of a string.
7. Subset sum problem.

#### Hard:

1. Solve Sudoku problem.
2. Regular expression matching.
3. Wildcard matching.
4. Remove invalid parentheses.

### 6. Trees

#### Easy:

1. Inorder traversal of a binary tree.
2. Preorder traversal of a binary tree.
3. Postorder traversal of a binary tree.
4. Level-order traversal (breadth-first search).
5. Check if a binary tree is a valid binary search tree.
6. Find the height of a binary tree.
7. Check if two binary trees are identical.

#### Medium:

1. Find the lowest common ancestor of two nodes in a binary search tree.
2. Serialize and deserialize a binary tree.
3. Construct a binary tree from preorder and inorder traversals.
4. Convert a binary search tree to a sorted doubly linked list.
5. Binary tree zigzag level order traversal.
6. Flatten a binary tree to a linked list.
7. Find the diameter of a binary tree.

#### Hard:

1. Recover a binary search tree that had two nodes swapped by mistake.
2. Find the kth smallest element in a binary search tree.
3. Maximum path sum in a binary tree.
4. Count the number of good leaf node pairs in a binary tree.

### 7. Graphs

#### Easy:

1. Depth-first search (DFS) traversal.
2. Breadth-first search (BFS) traversal.
3. Check if a graph is bipartite.
4. Find the number of islands in a 2D grid.
5. Check if two nodes are connected in an undirected graph.
6. Implement graph adjacency list and adjacency matrix.
7. Detect a cycle in an undirected graph.

#### Medium:

1. Topological sort.
2. Clone a graph.
3. Find all paths from source to target in a directed acyclic graph (DAG).
4. Dijkstra’s shortest path algorithm.
5. Minimum spanning tree using Kruskal’s algorithm.
6. Find the shortest path in an unweighted grid.
7. Count the number of strongly connected components in a directed graph.

#### Hard:

1. Find the shortest path in a weighted graph using Bellman-Ford algorithm.
2. Find bridges (critical connections) in a graph.
3. Implement the A\* search algorithm.
4. Traveling Salesman Problem (TSP).

### 8. Sorting and Searching Algorithms

#### Easy:

1. Bubble sort.
2. Selection sort.
3. Insertion sort.
4. Binary search in a sorted array.
5. Find the first occurrence of a target in a sorted array.
6. Search in a rotated sorted array.
7. Find the peak element in an array.

#### Medium:

1. Merge sort.
2. Quick sort.
3. Search for an element in a 2D matrix.
4. Find the kth largest element in an array.
5. Find the missing number in an unsorted array.
6. Search in a matrix sorted row-wise and column-wise.

## Logical and mathematical problems

### Logical and Mathematical-Based Questions

#### Easy:

1. **Palindrome Number**: Write a program to check if a given number or string is a palindrome.
2. **Prime Number Check**: Check if a given number is prime.
3. **Fibonacci Sequence**: Generate the first `n` Fibonacci numbers.
4. **Factorial Calculation**: Calculate the factorial of a given number.
5. **Armstrong Number**: Check if a number is an Armstrong number (e.g., 153 → 1³ + 5³ + 3³ = 153).
6. **Sum of Digits**: Find the sum of the digits of a given number.
7. **LCM and GCD**: Calculate the Least Common Multiple (LCM) and Greatest Common Divisor (GCD) of two numbers.

#### Medium:

1. **Prime Factors**: Find all prime factors of a given number.
2. **Perfect Number**: Check if a number is a perfect number (sum of its divisors equals the number).
3. **Find All Divisors**: Find all divisors of a given number.
4. **Number of Trailing Zeros in Factorial**: Find the number of trailing zeros in the factorial of a number.
5. **Check if a Number is a Power of Two**: Determine if a number is a power of two.
6. **Reverse Digits**: Reverse the digits of a number (e.g., 123 → 321).
7. **Palindrome Substrings**: Count the number of palindromic substrings in a string.

#### Hard:

1. **Sieve of Eratosthenes**: Find all prime numbers up to `n` using the Sieve of Eratosthenes algorithm.
2. **Largest Prime Factor**: Find the largest prime factor of a given number.
3. **Finding Square Root (without built-in functions)**: Implement a method to find the square root of a number (using binary search or Newton's method).
4. **Modular Exponentiation**: Implement an efficient algorithm for `(base^exponent) % modulus` without overflow.

### Additional Mathematical and Logical Challenges

#### Easy:

1. **Sum of N Natural Numbers**: Write a program to calculate the sum of the first `n` natural numbers.
2. **Check Leap Year**: Determine if a given year is a leap year.
3. **Sum of Even and Odd Numbers**: Calculate the sum of all even and odd numbers from 1 to `n`.
4. **Check for Armstrong Numbers within a Range**: Find all Armstrong numbers between two given numbers.
5. **Power of a Number**: Implement a function to calculate `a^b` (a raised to the power of b).
6. **Palindrome Word Check**: Check if a word is a palindrome without using built-in functions.
7. **Sum of Squares of Digits**: Calculate the sum of the squares of digits of a number (e.g., for 123 → 1² + 2² + 3² = 14).

#### Medium:

1. **Sum of Digits Until Single Digit**: Reduce a number by summing its digits repeatedly until a single digit remains.
2. **Kaprekar Number**: Check if a number is a Kaprekar number (e.g., 45 → 45² = 2025 → 20 + 25 = 45).
3. **Nth Prime Number**: Find the nth prime number.
4. **Greatest Product in an Array**: Find the greatest product of three numbers in an array.
5. **Hamming Distance**: Calculate the Hamming distance between two binary numbers.
6. **Happy Number**: Write a program to check if a number is a "happy number" (e.g., sum of the squares of its digits eventually reaches 1).
7. **Base Conversion**: Convert a given number from one base to another (e.g., decimal to binary, binary to hexadecimal).

#### Hard:

1. **Permutation of Numbers**: Generate all permutations of a given set of numbers.
2. **Find Missing Number in a Range**: Given a list of numbers from 1 to `n` with one missing, find the missing number.
3. **N-Queens Problem**: Solve the N-Queens problem, where no two queens can attack each other on an `n x n` chessboard.
4. **Magic Square**: Check if a matrix is a magic square (i.e., all rows, columns, and diagonals have the same sum).
5. **Count Primes in a Range**: Count the number of prime numbers between two given numbers.
6. **Pascal's Triangle**: Generate the first `n` rows of Pascal’s triangle.
7. **Josephus Problem**: Solve the Josephus problem, where people are standing in a circle and every `k-th` person is eliminated.

### Special Mathematical Problems

#### Easy:

1. **Binary to Decimal Conversion**: Convert a binary number to its decimal equivalent.
2. **Decimal to Binary Conversion**: Convert a decimal number to binary.
3. **Sum of Prime Numbers**: Find the sum of prime numbers less than or equal to a given number.
4. **Check if a Number is a Perfect Square**: Determine if a number is a perfect square.
5. **Find the Digit that Occurs the Most**: Count the frequency of digits in a number and find the most frequent digit.
6. **Generate a List of Fibonacci Primes**: Generate the list of Fibonacci primes up to `n`.
7. **Check if a Number is Palindromic in Multiple Bases**: Determine if a number is a palindrome in two different bases.

#### Medium:

1. **Sum of Two Squares**: Find two numbers whose squares sum up to a given number.
2. **Sum of Proper Divisors**: Calculate the sum of all proper divisors (excluding the number itself) of a number.
3. **Find the Smallest Number Divisible by All Numbers in a Range**: Find the smallest number that is divisible by all numbers in a given range.
4. **Find the Length of the Collatz Sequence**: Write a program to find the length of the Collatz sequence starting from a given number.
5. **Mersenne Primes**: Find all Mersenne primes less than or equal to `n`.
6. **Generate a Spiral Matrix**: Generate a `n x n` matrix with numbers arranged in a spiral pattern.
7. **Goldbach Conjecture**: Find two prime numbers that sum to a given even number.

#### Hard:

1. **Find Prime Numbers using Miller-Rabin Primality Test**: Implement the Miller-Rabin primality test for large numbers.
2. **Prime Number Theorem Approximation**: Approximate the number of prime numbers less than or equal to `n` using the prime number theorem.
3. **Chinese Remainder Theorem**: Solve systems of congruences using the Chinese Remainder Theorem.
4. **Catalan Numbers**: Generate the first `n` Catalan numbers.
5. **Knight's Tour Problem**: Solve the Knight’s Tour problem on an `n x n` chessboard.
6. **Counting Inversions in an Array**: Count how many pairs in an array are out of order.

### Miscellaneous Logical Challenges

#### Easy:

1. **FizzBuzz**: Print numbers from 1 to `n`, but for multiples of 3 print "Fizz", for multiples of 5 print "Buzz", and for multiples of both print "FizzBuzz".
2. **Count Vowels and Consonants**: Write a program to count the number of vowels and consonants in a given string.
3. **Palindrome Partitioning**: Partition a given string such that every substring is a palindrome.
4. **Find the Maximum and Minimum Element in an Array**: Find the maximum and minimum element in a given array.
5. **Check if a Number is Even or Odd Without Using Modulus Operator**: Check if a number is even or odd without using the modulus operator.
6. **Sum of Even Fibonacci Numbers**: Find the sum of all even Fibonacci numbers less than or equal to a given number.
7. **Find Repeated Characters in a String**: Identify the characters that repeat in a given string.

By practicing these types of problems, you’ll develop a solid foundation in logical and mathematical reasoning, which will help you tackle many coding interview questions efficiently.
